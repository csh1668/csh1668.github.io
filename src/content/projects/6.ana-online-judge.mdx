- 동아리 프로그래밍 대회 개최 및 알고리즘 문제 풀이를 위해 개발한 플랫폼
  - ANIGMA, ANAGETDON 등의 실제 동아리 대회 운영 사례 있음 [#](https://aoj.anacnu.kr/contests/15)
  - 대회 중 동시 접속 100여 명 환경에서 안정적인 운영 검증
- ICPC, JOI, COCI, DSPC 등 외부 대회 문제 1000개 이상 채점 가능, 누적 제출 10000건 이상
- 일반, 스페셜저지, 인터랙티브 등 다양한 문제 형식과 C, C++, Java, Python, Rust, Go, C#, JS 등 9개 이상의 프로그래밍 언어 지원
- 사용자가 자유롭게 문제를 출제할 수 있는 **창작마당** 제공
- 웹 서버는 Next.js 풀스택, 채점 서버는 안정성과 속도를 위해 Rust + Redis로 구현
- AWS 배포를 염두에 두고 S3 인터페이스와 호환되는 MinIO를 파일 저장소로 사용
- Socket Proxy 기반 실시간 서버 로그 모니터링 관리자 페이지 제공
- 관리자 페이지 혹은 CLI로 모든 관리 작업을 수행할 수 있음
  - LLM에게 자연어 명령만으로 문제 출제·대회 개설·사용자 관리까지 E2E 자동화 가능
