- **문제점**: 팀의 Vercel과 Supabase 사용으로 인해 월 수백 달러의 비용 발생 -> AWS로 이전하려고 봤더니 앱 하나 이전하는데 3시간 걸렸던 경험.
- **해결 방법**: 두 서비스를 대체하는 자체 플랫폼을 단독 설계 및 개발 추진하여, 이전보다 90% 이상 비용 절감. 원클릭으로 배포 가능
- **Vercel 대체**: Docker 기반의 빌드 엔진 구성, 배포 현황 확인, 로그 확인, 환경변수 설정 가능
- **Supabase 대체**: 공유 PostgreSQL에 앱별 DB/role 자동 프로비저닝. 웹 DB Studio, MinIO 기반 버킷 스토리지와 공개 미디어 도메인 제공. 소셜 로그인 인증 브로커까지 제공하여 마켓플레이스에서 원클릭 연결 가능
- 사내 대부분의 서비스를 이전했으며, 비개발자 팀원도 쓸 수 있는 UX로 전사 사용 중. MCP와 CLI 지원으로 AI 코딩 에이전트가 직접 배포까지 할 수 있도록 제공
